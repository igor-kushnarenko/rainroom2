# Плейбук: rainroom2 (по образцу campfire)

## 1. Заготовка
- Vite + Three.js, деплой на GitHub Pages через `.github/workflows/deploy.yml` (push в main → test → build → Pages).
- `npm test` (`node --test test/*.test.js`) — логика без браузера: настройки, хотспоты, часы/погода, тюнер.

## 2. Арт и слои
- Исходники: `art_src/off.png` (всё выключено) и `art_src/on.png` (всё включено) — один кадр, выровнены по пикселям (сдвиг 0,0; OFF на 1 px уже — дублируется край).
- `python3 tools/make_layers.py` → `public/layers/{aligned,half}/01_base … 05_laptop_on.png` и маски `public/layers/masks/{glass,neon}.png`.
- Свет: комната = OFF + Σ доля_i·(ON−OFF). Карты влияния `masks/light_rgb.png` (r лампа, g фонарь+свеча, b радио) и `masks/light_laptop.png` — разница ON−OFF отдана источнику по силе/расстоянию/цвету; сами приборы — жёсткие маски (нет утечек: экран ноутбука только от ноутбука). Всё вкл ≈ ON (скрипт печатает средний diff).
- Предметы перед дождём (радио с антенной, растение, кружка, крышка ноутбука) — вырезаны из маски стекла по силуэту, не горизонтальным клипом.
- Все координаты (хотспоты, экран ноутбука, пар, город для погоды) — в `SCENE` в `src/config.js`.

## 3. Эффекты
- Стекло: тонкие (~1 px) штрихи, независимые колонки со своими скоростью/фазой/длиной/прозрачностью, 3 слоя глубины, лёгкий наклон; маска стекла. Мягкий неон, молния. Учтите: в исходном арте уже нарисованы капли. Стекающая вода: капли разного размера идут рывками по извилистым путям (3 слоя колонок), оставляют тонкие мокрые следы; мелкие капли плавно растут и высыхают.
- Пар над кружкой: 3 шлейфа, дрейф вправо (как нарисованный пар). Город (только в маске стекла): окна кластерами 7x5 плавно гаснут/зажигаются (masks/city.png r), красные огни на шпилях мигают (g), вывески мягко «дышат», облака и туман — готовые мягкие спрайты `layers/fx/` (tools/make_clouds.py, дизеринг запечён): медленно плывут, «дышат», сменяются по прозрачности — без процедурного шума в пикселях (на реальных GPU он давал кольца); машины — крошечные огоньки 1–3 px/с по `SCENE.roads` (обведены по нарисованным улицам, проверка `python3 tools/road_debug.py`) в обе стороны (src/traffic.js).

## 4. Интерактив
- Клик по устройству — вкл/выкл (сохраняется). Hover — через `window` `pointermove`, лёгкая подсветка выключенного устройства.
- Колесо над радио — станции, в остальном кадре — сила дождя. Клавиши 1–4 — устройства, M — звук, F — весь экран, стрелки — меню (пульт).

## 5. Звук
- Процедурно: шум дождя, капли барабанят по стеклу (отдельный регулятор «капли по стеклу», частота растёт с силой дождя, порывы), гром, гул комнаты, щелчки.
- Радио — `src/radio.js` из campfire без изменений (CORS-плеер через WebAudio + запасной). Уровни низкие, подбирать по отзыву владельца.

## 6. Станции
- `node tools/merge_stations.mjs stations_in/*.json` → `public/stations.json` (https, без HLS, без дублей).

## 7. Интерфейс
- Меню в круглой кнопке ☰, раскрывается при наведении, сворачивается через 5 с. Настройки — `src/settings.js` (localStorage `rainroom2.settings.v1`).
- Вписывание: по умолчанию contain (весь кадр 16:9, поля — размытое затемнённое продолжение), «Заполнить экран» — cover (`settings.fill`). Математика — `src/fit.js`. Скриншоты экранов: `node tools/fitshots.mjs`.
- Ноутбук: панель часов натянута на четырёхугольник исходной панели (`SCENE.screen.quad`). Погода: open-meteo → запасной wttr.in → последняя сохранённая; без связи — «нет связи».

## 8. Цикл правки
1. Правка → `npm test` → `npm run build`.
2. `npx vite preview --port 4188` и `node tools/shots.mjs http://localhost:4188/ shots` (нужен playwright-core и /usr/bin/google-chrome).
3. Push только после «да» владельца → `gh run list -L1` → проверка на сайте.

## 9. Чек-лист релиза
- Дождь не рисуется поверх предметов на подоконнике при `?rain=1`.
- Все устройства кликаются, состояние переживает перезагрузку.
- Звук без перегруза; гром тихий и редкий.
- Телефон и ТВ-пульт; `?q=low` для слабых ТВ.
- Нет секретов в репо.

## Отладка
- `?nofx=clouds,fog,rain,drops,city,steam,pixel` — выключить эффекты по одному; `?prec=mediump` — проверить точность GPU. Облака и туман по умолчанию выключены: `?fx=clouds,fog`.
- В однострочных GLSL-строках не писать `//` — закомментирует остаток шейдера (так «пропали» машины). Скрипты скриншотов ловят ошибки консоли.
- `?devices=all|lamp,…`, `?rain=0..1`, `?thunder=1`, `?fill=1`, `?q=low`.
- Нарисованный пар над кружкой убран из исходников `tools/remove_steam.py` (уже применён к art_src; повторно не запускать).

## «Кольца» в небе (v9)
Причина — сам арт: в небе сгенерированной картинки слабые (±3–5 уровней) контурные разводы. Эталонный ресайз арта PIL-бикубикой даёт ту же ВЧ-энергию, что и рендер (5.67 vs 5.59), swiftshader/llvmpipe/mediump/mipmaps/без эффектов — без разницы.
Лечение: `tools/smooth_sky.py` (coring слабой детали внутри маски стекла, оригиналы в art_src/presky). Плюс сцена рендерится 1:1 к арту (1660x935) и масштабируется один раз бикубикой Catmull-Rom.
Проверка: equalize-кроп неба до/после (shots/v9_sky_*).
